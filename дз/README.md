# Segment Tree Calculator - Django Web Application

Веб-приложение для вычисления дерева отрезков с операциями OR и XOR, построенное на Django с REST API и современным веб-интерфейсом.

## 🚀 Возможности

- **Веб-интерфейс** для ввода данных и просмотра результатов
- **REST API** для программного доступа к функциональности
- **Кэширование результатов** - если такие входные данные уже вычислялись, результат берется из БД
- **Хранение истории** - все запросы пользователей сохраняются в базе данных
- **Отслеживание пользователей** - система запоминает, кто, когда и какие данные вводил

## 📋 Требования

- Python 3.8+
- Django 4.2+
- Django REST Framework
- SQLite (встроенная, используется по умолчанию)

## 🛠️ Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd дз
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
```

3. Активируйте виртуальное окружение:
```bash
# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate
```

4. Установите зависимости:
```bash
pip install -r requirements.txt
```

5. Выполните миграции:
```bash
python manage.py makemigrations
python manage.py migrate
```

6. Создайте суперпользователя (опционально, для доступа к админ-панели):
```bash
python manage.py createsuperuser
```

7. Запустите сервер разработки:
```bash
python manage.py runserver
```

8. Откройте браузер и перейдите по адресу: `http://127.0.0.1:8000/`

## 📖 Использование

### Веб-интерфейс

1. Откройте главную страницу в браузере
2. Введите степень двойки (n)
3. Введите массив из 2^n элементов
4. (Опционально) Добавьте обновления элементов
5. Нажмите "Вычислить"
6. Результат будет отображен на странице

### REST API

#### Вычисление дерева отрезков

**Endpoint:** `POST /api/calculate/`

**Запрос:**
```json
{
    "n": 2,
    "array": [1, 2, 3, 4],
    "updates": [
        {"p": 1, "b": 4},
        {"p": 3, "b": 4}
    ]
}
```

**Ответ:**
```json
{
    "initial_result": 4,
    "update_results": [1, 2],
    "from_cache": false,
    "input_data_id": 1,
    "result_id": 1
}
```

#### Просмотр истории запросов

**Endpoint:** `GET /api/user-requests/`

**Endpoint:** `GET /api/input-data/`

**Endpoint:** `GET /api/results/`

## 🗄️ Структура базы данных

### InputData
Хранит уникальные входные данные (n и массив). Использует хеш для предотвращения дубликатов.

### CalculationResult
Хранит результаты вычислений, связанные с входными данными.

### UserRequest
Хранит историю всех запросов пользователей с указанием времени, пользователя и IP-адреса.

## 🔧 Алгоритм

Приложение реализует дерево отрезков с чередующимися операциями OR и XOR:
- Для нечетных уровней (снизу вверх) используется операция OR
- Для четных уровней используется операция XOR

## 🔒 Особенности реализации

1. **Проверка дубликатов**: Система вычисляет SHA256 хеш входных данных и проверяет наличие в БД перед вычислением
2. **Оптимизация**: Если входные данные уже были вычислены, результат берется из БД без пересчета
3. **Отслеживание**: Каждый запрос сохраняется с указанием пользователя, времени и IP-адреса
4. **API-first подход**: Backend полностью отделен от Frontend, все взаимодействие через REST API
